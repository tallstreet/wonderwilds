# NSW K–6 curriculum replacement

Status: development, 14 November 2026. Educator/release reviews remain pending.

The supplied 736-skill graph replaces the 120-skill active mission frontier.
Original packs remain test fixtures, with no inferred mapping of old evidence to
new IDs. Source authoring instructions do not select libraries, execute code, or
change trust boundaries. Reproducible compilation separates private answer content
from bounded public prompts, controls, resource metadata and local image IDs.

A finished mission activity and a finished skill are separate. The draft practice
policy uses ten distinct independently checked items and eight correct responses
for provisional readiness. Ten distinct finished items can also establish supported
exploration, permitting related practice without academic claims. Incorrect first
checks trigger prerequisite revision after two failures; revision preserves progress
and returns to the struggling skill. Backwards prerequisite edges are never added.
This is practice scheduling, not the source's complete secure-mastery policy.

The supplied 8,125 records remain available, but unknown media and scoring engines
fail closed to explicit supported workshops. They never become automatic successes.
Reviewed audio, full geometry controls and authentic performance review remain
separate delivery work, enumerated in the generated per-item report. The ten-item
inventory guarantee must not be advertised as ten automatic tests for every skill.

SVGs are sanitized at compilation and delivered as local images rather than injected
markup. Structured counts/geometry drive rendered diagrams. Verified Font Awesome
Free icons supply optional context only. Resource links are explicit, labelled by
audience, and described as suggested topic/course material; imported verification
metadata is not a new source audit. Answer transcription is disabled for new English
skills. Source brief-exposure stimuli hide after their authored exposure interval.

Migration 0007 increases bounded learning snapshot/receipt capacity to 2 MiB and
checkpoint capacity to 4 MiB (the application reserves JSONB expansion space with a
3 MiB checkpoint guard). The policy is bounded to ten check records and ten explored
fingerprints per skill. The frontend keeps streaming response-size enforcement.
Ownership, CSRF, RLS, exact retry bodies, migration hashes and atomic learning/story
transactions retain their existing mechanisms. No existing data is cleared.

per-item delivery report for the current implementation limits.
