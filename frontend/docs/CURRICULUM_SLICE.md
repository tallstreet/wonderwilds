# Clover Meadow curriculum slice

This prototype samples Foundation-level quantity, sharing, and sequence concepts. It is not a complete curriculum or validated assessment.

| Activity / skill    | Objective                                       | Prerequisite                                    | Model                                                   | Likely misconception                                              | Support                                                            |
| ------------------- | ----------------------------------------------- | ----------------------------------------------- | ------------------------------------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------ |
| Bridge / missing-10 | Find the missing part of ten when six are given | Count objects to ten                            | Ten bridge spaces, six fixed planks, add/remove objects | Confusing total with missing part; counting initial objects again | Count empty spaces, count on from six, worked answer four          |
| Picnic / share-6    | Share six objects equally between two groups    | One-to-one counting                             | Basket and two plates with moveable berries             | Using all berries but making unequal groups                       | Alternating distribution, compare groups, worked answer three each |
| Garden / count-1    | Continue 1, 2, 3, 4 with five                   | Count small groups, connect quantity to numeral | Each flower group has a numeral and countable flowers   | Repeating four or skipping five                                   | Notice one-more relation, count aloud, worked answer five          |

Allowed milestone values are authored and fixed. Future variants should use small quantities first, preserve the target skill, and independently validate arithmetic. Before increasing difficulty, seek repeated independent evidence across different quantities and contexts, not repeated completion of this exact encounter. Current UI deliberately reports observations rather than mastery.

Story gates are independent of evidence: supported bridge completion opens the river crossing and supported activities still earn friendship stars. Garden access depends on bridge story completion; the picnic is available immediately. Once all three stories are complete Pip follows the player.

Reference direction: Australian Curriculum Foundation knowing-numbers work sample, linked in the main implementation plan. Educator review and child usability testing remain necessary.
